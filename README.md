# Minimal Maven Kotlin and QueryDSL Example

As I could not locate a single working and up-to-date example implementation of QueryDSL in a Kotlin-Maven project, I created my own.

The example uses Spring Boot 4.1, Kotlin 2.4, Java 17+, and the maintained OpenFeign QueryDSL fork.

If you want to find out more, give my [Blog Article](https://felixzett.com/articles/minimal-maven-kotlin-querydsl-example/) a visit.
